# ClearGuard

ClearGuard это приложение для Android, которое блокирует порнографию через локальную фильтрацию DNS и, как резерв, через чтение текста на экране. Главное отличие в том, что отключение защиты никогда не происходит мгновенно: любой запрос на ослабление защиты проходит период ожидания и уведомляет доверенного партнёра до вступления в силу.

## Как это работает

Основная блокировка работает через локальный VPN, который фильтрует DNS запросы по списку заблокированных доменов. Служба специальных возможностей читает видимый текст на экране как дополнительный слой, чтобы поймать контент, прошедший мимо фильтра DNS. Любое действие, ослабляющее защиту, например отключение блокировки или удаление домена, создаёт отложенный запрос с PIN кодом, задержкой и уведомлением партнёра. Усиление защиты всегда происходит немедленно.

## Архитектура

Код на Flutter находится в `lib`, разделён на `data` (сервисы и репозитории), `domain` (модели и бизнес правила) и `ui` (экраны и view models). Нативный код для Android находится в `native_android`, вместе со службой VPN, монитором экрана и инструкциями по интеграции в сгенерированный проект Flutter.

## Ограничения

Блокировка по DNS не останавливает прямой доступ по IP адресу. Разрешение VPN и служба специальных возможностей могут быть отозваны владельцем устройства в настройках системы, и ни одно приложение без MDM не может это предотвратить. Ничего здесь ещё не скомпилировано, так как на этой машине не установлены ни Flutter, ни Android SDK.
