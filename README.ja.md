# ClearGuard

ClearGuard は、ローカル DNS フィルタリングによってポルノコンテンツをブロックし、補助として画面上のテキストを読み取る Android アプリです。中心となる特徴は、保護の無効化が絶対に即座には行われないことです。保護を弱めるすべての要求は待機時間を経て、有効になる前に信頼できるパートナーに通知されます。

## 仕組み

主なブロック機能はローカル VPN 上で動作し、ブロック対象ドメインのリストに基づいて DNS クエリをフィルタリングします。アクセシビリティサービスは追加の層として画面上に表示されるテキストを読み取り、DNS フィルターをすり抜けたコンテンツを検出します。保護を無効化したりドメインを削除したりするなど、保護を弱める操作は、PIN、待機時間、パートナーへの通知を伴う保留中のリクエストを作成します。保護を強化する操作は常に即座に反映されます。

## アーキテクチャ

Flutter のコードは `lib` にあり、`data`(サービスとリポジトリ)、`domain`(モデルとビジネスルール)、`ui`(画面とビューモデル)に分かれています。Android のネイティブコードは `android/app/src/main/kotlin` にあり、VPN サービスと画面監視サービスに加えて、標準の Gradle/AGP プロジェクト構成が含まれます。

## 制限事項

DNS ブロックは IP アドレスへの直接アクセスを止めることはできません。VPN 権限とアクセシビリティサービスは、端末の所有者がシステム設定から取り消すことができ、MDM 以外のアプリではそれを防ぐことはできません。

## 実行方法

```bash
flutter pub get
flutter test
```

Android 側については `android/README.md` を参照してください。ローカルで何も設定せずに APK をビルドするには、Actions タブから `Build Android app` ワークフローを実行してください。
